# Drone Designer Lab

لعبة تعليمية تفاعلية لتصميم درون مناسب لمهمة محددة.

## المميزات
- 6 مهمات: سباق، تصوير، توصيل، إنقاذ، زراعة، فحص.
- اختيار الهيكل.
- 4 / 6 / 8 محركات.
- نوع المحركات.
- حجم المراوح.
- البطارية.
- وحدة التحكم.
- الكاميرا / الحساسات.
- معدات المهمة.
- معدات السلامة.
- نموذج درون يتغير بصرياً مباشرة.
- Performance Bars:
  - السرعة
  - الثبات
  - الطاقة
  - الحمولة
  - الحساسات
  - السلامة
- Compatibility Score من 100.
- فحص للتوافق الميكانيكي بين المكونات.
- Test Flight للمهمة.
- تخصيص اللون والاسم وLED والمراوح.
- شاشة اعتماد نهائية وميداليات حسب التصميم.

## ملاحظة تعليمية
القيم داخل اللعبة نموذج مبسط لأغراض تعليم الأطفال مفاهيم:
- المفاضلات الهندسية
- أن المهمة تحدد التصميم
- أن كل ميزة لها تأثير على ميزات أخرى

وليست أداة هندسية لحساب أداء درون حقيقي.
